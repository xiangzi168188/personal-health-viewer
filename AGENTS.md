# Personal Health Viewer site

This repository contains three public, static information pages for a planned personal health-data viewer.

- Publish only the static files in `docs/` as a GitHub Pages project site.
- Do not add health records, OAuth credentials, tokens, analytics, forms, or client-side calls to wearable APIs.
- Keep the pages accurate about the application's actual capabilities and data handling. No Oura data connection is active.
- Before changing data collection or sharing, update the privacy policy and terms to reflect the implemented behavior.
- The site is separate from the local OAuth callback and from the private OpenClaw workspace.

See `README.md` for deployment and `ROADMAP.md` for current status.
