Privacy Policy

Effective September 27, 2026.

Current website

This static website has no account form, tracking script, analytics, or health-data upload. It does not request or store wearable health records, OAuth credentials, or access tokens. No Oura data connection is active.

GitHub Pages hosts this website and may process ordinary web-access information under GitHub's privacy statement.

Use, sharing, and retention

Because this website does not receive health data, it does not use, share, retain, or sell health data. There is no health data held by this website to access, correct, or delete.

Future changes

Before enabling any wearable-data connection, this page will be updated to describe the actual data collected, its purpose, storage location, sharing, retention, deletion, and consent controls. A future AI use would require a permitted integration path and separate user consent; none is active.

Contact

For privacy questions, contact the owner through the GitHub profile.
