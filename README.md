# Personal Health Viewer site

Public information pages for a planned private, read-only health-data viewer. The site itself does not collect health data or perform OAuth.

## Pages

- `docs/index.html`: application overview
- `docs/privacy.html`: current privacy practices
- `docs/terms.html`: terms for this informational site

The site is published from `main` / `docs` in the public repository `xiangzi168188/personal-health-viewer`:

- Website: https://xiangzi168188.github.io/personal-health-viewer/
- Privacy Policy: https://xiangzi168188.github.io/personal-health-viewer/privacy.html
- Terms of Service: https://xiangzi168188.github.io/personal-health-viewer/terms.html
